Audio Tab Closer Privacy Policy

Privacy Policy

Audio Tab Closer helps you identify, open, and close Chrome tabs that are producing audio. This policy explains the limited browser information it uses to provide that feature and how that information is protected.

Effective September 12, 2026 Version 1.0
01

Information the extension handles

When you open the extension, Audio Tab Closer uses Chrome’s Tabs API to identify tabs that Chrome marks as audible. For those tabs, it processes the tab title, URL or hostname, tab ID, window ID, and audible status so you can recognize and manage the source of sound.

This information may qualify as web browsing activity under Chrome Web Store policies even though it is processed only on your device. The extension does not read or modify webpage content.

02

How the information is used

The information is used only to provide the extension’s user-facing features:

  • show tabs that are currently producing audio;
  • let you switch to or close a tab you select;
  • keep the displayed list accurate when a tab closes; and
  • return you to the originating tab after closing a destination selected from the popup.

It is not used for analytics, profiling, advertising, marketing, or any unrelated purpose.

03

Storage and retention

Audio Tab Closer uses chrome.storage.session to temporarily store numeric tab IDs and a boolean resume flag. This supports the return-and-reopen flow after you close an audio tab.

Session data remains in browser memory only and is cleared when Chrome or the extension restarts. Tab titles, URLs, and hostnames are not stored by the extension.

04

Sharing and transfer

The extension does not transmit user data to the developer, external servers, service providers, advertisers, or other third parties. It does not sell user data. It contains no analytics, tracking, or remote code.

05

Chrome Web Store Limited Use

Audio Tab Closer’s use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide the extension’s single purpose, is not transferred for unrelated purposes, is not used for personalized advertising, and is not made available for human review.

06

Security

The extension reduces privacy risk by keeping processing local, requesting only the tabs and storage permissions, and making no external network requests. No method of software operation is risk-free, but Audio Tab Closer is designed to avoid transmitting or persistently storing browsing information.

07

Changes to this policy

This policy may be updated if the extension’s functionality or data practices change. The effective date at the top of this page will be revised when an update is published. Material changes will be reflected in the Chrome Web Store listing as required.

08

Acknowledgement

By installing or using Audio Tab Closer, you acknowledge that you have read this Privacy Policy.
